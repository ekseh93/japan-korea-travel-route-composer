# ADR-006: AI를 선택적 설명 Adapter로 제한

- 상태: 승인
- 일자: 2026-08-15

## 맥락

사용자는 감성, 쇼핑 같은 자연어 취향을 입력할 수 있지만 결과의 장소와 순서를
AI가 임의 생성하면 재현성, 출처, 영업시간과 비용을 검증하기 어렵다.

## 결정

후보 필터, 점수, 지역 군집, 이동시간과 일정 편성은 결정론적 도메인 로직만
수행한다. 기본 배포는 템플릿 기반 설명을 사용한다. AI는 명시적으로 활성화한
경우에만 다음 두 작업을 수행한다.

1. 자유서술을 승인된 ThemeTag와 제약 후보로 변환한다.
2. 선택된 Place, 점수 구성과 승인 Evidence 범위 안에서 설명을 자연스럽게 쓴다.

AI 출력은 Schema 검증 후 허용 Tag만 채택하며 장소 ID, 순서, 시간, 출처 URL을
추가·변경할 수 없다. 원문 커뮤니티 리뷰를 Prompt에 대량 전송하지 않는다.

## 결과

AI 키나 과금 없이 서비스가 동작하고 결과를 재현할 수 있다. 자연어 이해 범위는
좁아지지만 사용자가 구조화 조건으로 수정할 수 있다. Provider 도입에는 별도 비용,
개인정보, 데이터 처리 약관 ADR이 필요하다.
