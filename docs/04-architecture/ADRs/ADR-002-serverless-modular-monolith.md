# ADR-002: AWS 서버리스 모듈러 모놀리스

- 상태: 승인
- 일자: 2026-08-15

## 맥락

초기 사용량은 불확실하고 운영자는 1명이다. 고정비와 컨테이너 운영을 피하면서
DDD 경계를 코드로 표현해야 한다.

## 비교

| 선택지 | 유휴 비용 | 운영 부담 | 초기 적합성 |
|---|---:|---:|---|
| HTTP API + 단일 Lambda | 낮음 | 낮음 | 높음 |
| Context별 Lambda | 낮음 | 중간 | IAM·배포 단위가 과도함 |
| ECS/Fargate + ALB | 고정비 있음 | 중간 | 상시 서버가 필요 없음 |
| EC2 | 고정비 있음 | 높음 | 패치·가용성 관리가 과도함 |

## 결정

API Gateway HTTP API와 하나의 Lambda에 모듈러 모놀리스를 배포한다. DDD
Context는 package 의존성 테스트로 분리하고, 네트워크 서비스로 나누지 않는다.

## 결과

배포와 로그는 단순하지만 Lambda 크기와 콜드 스타트가 증가할 수 있다. 실제 지표로
패키지 크기 또는 서로 다른 확장 요구가 확인될 때만 Context별 Lambda 분리를
검토한다. NAT Gateway, ECS, EC2와 ALB는 MVP에서 생성하지 않는다.
